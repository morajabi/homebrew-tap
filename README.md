# morajabi/homebrew-tap

Homebrew tap for [poo](https://github.com/morajabi/poo), which finds and safely frees the
disk space your dev work eats: build output, caches, simulators and agent worktrees.

```sh
brew install morajabi/tap/poo             # CLI (macOS and Linux)
brew install --cask morajabi/tap/poo-app  # Poo.app, with its CLI linked as `poo`
```

Install one or the other: both put `poo` on your PATH, and the app's copy updates with the app.

The files here are generated from [`packaging/homebrew`](https://github.com/morajabi/poo/tree/main/packaging/homebrew)
by poo's release workflow. Send changes there.
